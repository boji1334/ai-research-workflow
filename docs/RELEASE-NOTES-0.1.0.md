# v0.1.0 — 工业视觉科研实验 skill

面向 Codex 的工业视觉、缺陷检测及相关小样本、自监督研究规程。

- 项目事实访谈先于论文目标与周期确认。
- 查新与机制设计、创新模块审查、有限小试、完整实验和结果复核。
- 初次无提升后最多两轮小规模修复；保留已知增强与负结果。
- 可选的轻量协议校验和运行登记工具，无第三方 Python 依赖。
- 核心工作流自包含，无需部署 AI Scientist v3、Docker 或完整上游技能库。

这是早期预发布版本。软件测试和隔离行为检查的范围见仓库 `docs/VALIDATION.md`；真实工业视觉项目的端到端研究验收尚未完成。

安装目录：`skills/industrial-vision-research`。可使用 Codex 的 skill-installer，或将该目录复制到项目 `.agents/skills/`。压缩包解压后顶层 `industrial-vision-research/` 即为技能目录。

本项目原创内容采用 MIT 协议。设计来源固定到对应上游提交并在技能内记录。
