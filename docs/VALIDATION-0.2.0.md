## Isolated behavior checks / 隔离行为检查

Two Codex subagents receive only the assigned skill and one raw synthetic packet, with separate fresh contexts (`fork_context=false`). They receive no expected verdict, parent diagnosis, other report or shared issue ledger. Each may write only its own evaluation output directory. The packets prohibit network, training, installation, live research access, repository edits and external messages.

- [Research-positioning packet](../tests/fixtures/research-positioning/project.md): existing literature, fixed task, proposed directions, inherited scores, an exhausted candidate family and resource reservations.
- [Pilot-admission packet](../tests/fixtures/pilot-admission/project.md): a candidate using familiar components, supplied method excerpts, scoped review comments, implementation prerequisites and a finite pilot.

These are synthetic procedure exercises, not algorithm benchmarks, a live literature survey or external peer review. Context isolation relies on separate conversations and scoped instructions, not filesystem access controls. Reports are frozen before the parent inspects and summarizes them; actual observations and hashes are recorded after completion.

## Limits / 验证边界

No real training or new scientific contribution is validated by these fixtures. This release does not establish improved real-project research speed, novelty-discovery success, model gains, journal readiness or autonomous scheduling. Those require actual project evidence and fair experiments. New positioning, review scope and budget decisions remain procedural responsibilities; the unchanged registry does not enforce them.
